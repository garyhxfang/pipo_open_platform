# Create Lark document

This Edge Function creates a Feishu document from the structured requirement Markdown generated by the capability map.

## Required secrets

```bash
supabase secrets set \
  LARK_APP_ID=cli_xxx \
  LARK_APP_SECRET=xxx \
  LARK_DOC_DOMAIN=https://bytedance.feishu.cn
```

Optional shared folder:

```bash
supabase secrets set LARK_FOLDER_TOKEN=fldcnxxx
```

The Feishu application needs permission to create and edit new documents. When `LARK_FOLDER_TOKEN` is set, the application must also have write access to that folder.

## Deploy

```bash
supabase functions deploy create-lark-document
```

JWT verification remains enabled, so users must sign in to Supabase before generating a document.
